# AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides ATS score along with improvement suggestions.

## 🚀 Features
- Upload resume (PDF)
- ATS score generation
- Keyword matching with job roles
- Suggestions for improvement

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
